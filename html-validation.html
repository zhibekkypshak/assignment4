Task 1. HTML5 Validation

Built-in browser validation: required, type="email", maxlength, minlength. Try submitting an empty form or a wrong email.




How it works

  • required – the field cannot be empty.
  • type="email" – browser checks the format (must contain @ and a domain).
  • maxlength / minlength – limits the number of characters.
